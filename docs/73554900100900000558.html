SAP Engineering Control Center interface to AutoCAD

General Information

This product helps customers to integrate AutoCAD into SAP PLM. The interface allows storing CAD ﬁles inSAP’s Document Info Record and document structures. The product provides additional menu entries in theCAD system and connects the CAD system with SAP Engineering Control Center.

Preconditions

SAP Engineering Control Center needs to be installed and conﬁgured. Please refer also correspondingdocumentation and installation guides for SAP Engineering Control Center.

Procedure

Please download the software to your local client, start the installer and follow the instructions.

Maintenance Strategy

SAP plans to ship minor releases on a yearly basis. Additionally, we plan to deliver Support Packages andFeature Packages on a regular basis.

SAP recommends always installing the latest Support Packages and Feature Packages.

A Support Package will contain corrections; Feature Packages will contain new functionality. SAP plans todeliver a new patch or support package for the CAD interface within 3 months after a new CAD release isavailable for customers.

Support

In case you encounter problems when installing, upgrading or running SAP Engineering Control Center interface to AutoCAD, report an incident on the SAP Support Portal using component PLM-ECC-ACD.
